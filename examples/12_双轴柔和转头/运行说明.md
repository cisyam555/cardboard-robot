# GPIO5 左右转头，GPIO6 上下点头

## 先看两轴动作

1. 舵机信号线：左右 GPIO5，上下 GPIO6；电源沿用外部稳压 5V，ESP32 与舵机共地。
2. 在 Thonny 先停止原程序，把新版 `firmware/config.py` 和 `firmware/servo.py`
   保存到开发板根目录。只运行本演示不需要 OLED、红外、触摸；原 main.py 仍会开机运行，
   所以每次演示前先按停止。
3. 上传后重启开发板以清除模块缓存，再按停止中断原 main.py。在电脑打开 `head_turn_demo.py`，按 F5 运行。不要覆盖开发板的 main.py。
4. 依次展示左看、右看、抬头、低头、双轴联动、回中，完成后保持中位。
5. 停止前扶住头部；停止会关闭 PWM，头部可能下垂。

第一次空载或卸下头壳测试。启动时不知道实际位置，首次回中不能保证平滑。
当前两轴均限制为中位 1.5ms ±0.1ms；实际角度由舵机、连杆和安装决定。
不要直接扩大到 0～180°，先确认机构不会卡住。柔和算法只是平滑指令，没有位置反馈。

## 方向、速度怎么改

在开发板 `config.py` 中改完重启：

- 左右相反：`PAN_DIRECTION` 在 `1` / `-1` 之间切换。
- 上下相反：`TILT_DIRECTION` 在 `1` / `-1` 之间切换。
- `STEP_NS`：每次更新最多改变的脉宽，越小越慢。
- `RAMP_STEP_NS`：起动时每次增加的步幅，越小起步越缓。
- `STEP_INTERVAL_MS`：更新间隔，默认 20ms。不是 PWM 周期的调速开关。

新 `servo.py` 在起动、接近目标和中途换向时使用较小步幅；左右、上下共用同一驱动。

## 再做参考笔记的手势互动

把 `firmware/` 全部 9 个 .py 文件更新到开发板，`MODE = "standalone"`，重启：

| 输入 | 反应 |
| --- | --- |
| GPIO4 左红外检测到手 | GPIO5 向左转 |
| GPIO3 右红外检测到手 | GPIO5 向右转 |
| 两侧都检测到 | 朝中间 |
| GPIO10 触摸有效 | GPIO5 回中，GPIO6 低头，OLED 触摸表情 |
| 手离开检测区 | 短暂等待后回中 |

这是左右区域跟随。两个数字红外无法测量手的高度和连续坐标，因此不能靠这两个输入
实现精确的上下手部追踪。演示里的抬头是预设动作，互动里的低头由触摸触发。
要上下自动追踪，需要另外增加可判断高度的传感器或摄像头。

已有 ROS2 模式继续使用同一个舵机驱动，因此也会获得柔和起停效果；
切换方法见 `docs/ros2.md`。本次无法播放参考链接中的视频，只能读取笔记说明和封面，
不声称动作时序、速度或角度与原视频完全一致；本代码是项目自己的实现。
