# 视频转头：先看动作，再接入感应

程序文件：`robot_video_turn.py`，使用 ESP32-C3 上的 MicroPython。
这是根据视频可见动作、你现有的模块和接线编写的学习版本，不是作者源码。
已经保留之前选择的普通、触摸半垂眼、红外亮眼微笑表情。

## 第一次：自动演示

1. 先卸下头壳。两只舵机可以暂时不组装成机构，用白色舵盘当指针观察；装舵盘前先回中、断电，不能带电拆装。
2. 不改接线：GPIO5 是左右舵机，GPIO6 是低头舵机。两只由电源板绿色 5V 供电，黑色 GND 与 ESP32 的 G 相连。ESP32 继续用 USB，ESP32 的 5V 和 3.3 引脚不接外部输出。
3. 在 Thonny 点“文件 → 打开 → 此电脑”，打开本文件夹的 `robot_video_turn.py`。
4. 右下角确认解释器是 MicroPython (ESP32)，端口选当前连接的开发板。
5. 文件顶部保持 `MODE = "demo"`，按绿色运行按钮／F5。若问保存位置，可先保存到此电脑；Thonny 会将当前脚本发到开发板执行。
6. 两只先回中，然后：第一只向左、回中、向右、回中；第二只低头、抬回。演示只做一遍，随后持续保持中位，按红色停止按钮结束。

自动演示不读取红外、触摸或屏幕，屏幕不变是正常的。只运行这个文件，不必把旧的联动程序一起运行。

## 第二次：感应互动

1. 按红色停止，找到文件顶部 `MODE = "demo"`。
2. 改成 `MODE = "interaction"`，保存，重新按 F5。
3. 开发板根目录需要之前已经使用成功的 `ssd1306.py`；电脑有这个文件不代表开发板里也有。
4. 手放在左模块前面：向左转；放在右模块前面：向右转。两边同时触发：回中并显示靠近表情。
5. 两边都没检测到：保留上次方向约 0.4 秒，再缓慢回中。
6. 摸头：优先朝中间并低头，显示你选的半垂眼表情；松开后按红外状态继续动作。没有感应时正常眨眼。

左和右按“你面对机器人屏幕”的方向定义。机器人自身的左右与你看到的左右相反。
红外是两个开关量，只知道有没有物体，无法判断手的连续角度和精确距离。这版在左、中、右之间平滑过渡，不是视觉追踪。
视频中涉及的具体角度、速度和内部控制方式无法仅从画面确定，实际幅度还需要机械安装后校准。

## 方向反了改哪里

- 左侧检测到却向右：把 `PAN_DIRECTION = 1` 改为 `PAN_DIRECTION = -1`。
- 低头变成抬头：把 `TILT_DIRECTION = -1` 改为 `TILT_DIRECTION = 1`。
- 转动太快：把 `STEP_NS = 4000` 改为 `2000`，会更慢。
- 先不要调大 `PAN_RANGE_NS`、`TILT_RANGE_NS`。目前程序限制在已试过的 1400000～1600000 纳秒内。装好后需检查间隙、重新校准，才能另行扩大范围。

## 注释应该按什么顺序看

1. **顶部设置**：引脚决定控制哪只舵机，脉冲宽度决定位置。
2. **SmoothServo**：保存当前指令和目标指令；每次只改一点脉宽，所以动作缓慢。SG90 自己处理转轴位置，程序没有读回实际角度。
3. **StableInput**：信号连续稳定 60 毫秒才承认变化，减小检测边缘造成的来回抖动。
4. **choose_action**：根据三个传感器决定“去哪”，触摸优先。
5. **run_interaction**：反复读取输入、更新两只舵机、改变表情；没有等待整个动作完成的长暂停，因此能中途改变方向。
6. **finally**：按停止或发生错误时关闭 PWM。关闭后舵机不再主动保持头部，需要先扶住头壳。

50Hz 表示一秒钟重复 50 次控制脉冲，不表示一秒转 50 圈。
1500000 纳秒等于 1500 微秒，约是普通 SG90 的中位指令；不是 150 万度。
以前的程序动作 600 毫秒后切断脉冲，这版保持 PWM，负载下才有保持位置的能力。
保持能力仍受电源、负载和机械结构限制；卡住、明显持续嗡鸣或发热时要停止检查，不靠加大指令硬顶。

## 安装后再做什么

先装空头壳，检查小范围动作不会卡住、线不会拉紧，再装屏幕。第一次上电回中可能直接转到中位，因为程序不知道当前真实角度。
不要用手压着头强迫舵机转动。停止前扶住头壳，改机械连接或接线前断开外接电源和 USB。
此阶段先用 F5 测试，不急着存成 `main.py`。本次已在电脑模拟关键控制逻辑，尚未在你的实际舵机上运行这份新程序。
