# 不用面包板的接线方案

当前仍用 USB 给 ESP32 供电，外部电源板给屏幕、传感器和舵机供电。
电源模块的适配器沿用已经测试过的那一个。

更改接线前：先拔外接适配器电源，再拔 USB。

| 模块 | 电源正极 | GND | 信号接 ESP32 |
| --- | --- | --- | --- |
| OLED 屏幕 | VCC → 电源板黄色 3.3V | 黑色 GND | SDA → 0；SCL → 1 |
| 触摸模块 | VCC → 电源板黄色 3.3V | 黑色 GND | SIG → 10 |
| 左红外 | VCC → 电源板黄色 3.3V | 黑色 GND | OUT → 4 |
| 右红外 | VCC → 电源板黄色 3.3V | 黑色 GND | OUT → 3 |
| 转头舵机 | 红线 → 电源板绿色 5V | 棕/黑线 → 黑色 GND | 橙/黄线 → 5 |
| 点头舵机 | 红线 → 电源板绿色 5V | 棕/黑线 → 黑色 GND | 橙/黄线 → 6 |
| ESP32 | 当前由 USB 供电 | G → 电源板黑色 GND | — |

共需要 4 路 3.3V、2 路 5V、7 路 GND。信号线直接连接 ESP32。
同一标字区域的空余输出针可用于分线；若插针不足，使用同电位分线器。
GND 分线器的所有分支应相通，并且只连接 GND。
需要根据电源板实际针数确定是否加 GND 分线器，不能把两个杜邦插头硬挤在同一针上。

移除开发板 3.3 引脚到面包板的旧分电线；不要把开发板与电源板的 3.3V 输出相连。
红色 VIN 是适配器的原始输入电压，不能接上述模块。
当前连接 USB 时，外部电源板的 5V 不连接 ESP32 的 5V。

所有板背面的焊点、针脚保持绝缘，固定时保留 USB 插口和螺丝的操作空间。

接线核对后：插 USB、接通适配器，在 Thonny 运行 `robot_left_right.py`。
最终脱离电脑运行，另需把程序保存为开发板上的 `main.py`，并单独切换 ESP32 的供电。
切换时先断开全部电源，再拔掉 USB，才连接电源板绿色 5V → ESP32 的 5V。
以后重新连接 USB 前，先断电并移除这根外接 5V 线。
