# 2026-10-18 实物运行记录

本记录对应 ESP32-C3 SuperMini、MicroPython v1.29.0，以及本仓库 `firmware/` 的正式 9 模块版本。没有使用资料包的封闭固件。测试时 ESP32 经电脑 USB 供电，舵机及传感器使用原外接电源模块并共地。

## 当前程序与动作

- GPIO5 水平舵机：左 / 右目标 1200000 / 1800000ns，默认略向右 1560000ns。
- GPIO6 俯仰舵机：默认抬头 1600000ns；红外感应再抬高到 1620000ns；触摸低头 1400000ns。
- 上电先输出俯仰默认位置，等待 700ms，再输出水平默认位置，等待 700ms 后启动互动。
- 触摸优先；松手反馈继续保持约 1 秒。红外消失约 0.4 秒后回默认姿势。
- OLED 只绘制原有表情和眨眼，移除了模式及 L/R/T 调试字母。USB 原始电平、模式和脉宽遥测保留。
- 默认 `MODE = "standalone"`，支持既有 USB/ROS2 接管、超时回退和回默认姿势后交接。

## 验证过程与结果

1. 更新前备份板上全部 Python 文件，包括原有 `boot.py`。备份保存在电脑的学习目录，不上传购买资料包或备份到本仓库。
2. 上传全部 9 个正式 `.py` 文件，暂存和最终文件均逐个做 SHA256 校验；板上内容与当前电脑文件一致。
3. 发出真实重启，程序从设备内的 `main.py` 自动启动并进入 `standalone`，没有记录到启动报错。
4. 通过既有 USB 命令接口进行动作链路测试，以下指令值均记录到达：

   | 检查 | 水平 / 俯仰指令（ns） | 结果 |
   | --- | --- | --- |
   | 默认姿势 | 1560000 / 1600000 | 通过 |
   | 左转并抬头 | 1200000 / 1620000 | 通过 |
   | 右转并抬头 | 1800000 / 1620000 | 通过 |
   | 低头 | 1560000 / 1400000 | 通过 |
   | 回默认姿势 | 1560000 / 1600000 | 通过 |

5. 测试后退出 USB 接管，确认恢复 `standalone`，并继续收到独立传感器观察数据；程序保持运行。
6. 用户观察新版动作后明确反馈：**“动作正常，没有异响”**。
7. 电脑端 27 项逻辑测试通过，38 个 Python 文件语法检查通过。

## 触摸与此前异响

此前已独立验证过真实触摸：修复头顶感应引线固定后，408 条遥测中触摸原始电平出现 0 和 1，低头指令达到 1400000ns，用户确认“可以了”。

本次新版自动测试中的低头由 USB 命令触发，不能将它当作又完成了一次真实触摸验收；实际触摸仍应在独立模式下复查。

调整默认姿势后，用户曾报告通电时出现“咔吧”声并低头，随后断电。该现象的根因没有证据确认。后续新版测试中用户反馈没有异响，不代表软件修复了齿轮、固定或供电问题；若再次出现应立即断电检查。

## 验证边界与离线运行

遥测脉宽是程序发给舵机的指令，SG90 没有角度反馈，不能据此证明真实角度、安装间隙或长期负载可靠性。本次未重新运行真实 ROS2 DDS 全链路。

程序已实际保存在设备内，不是只从电脑临时 F5 运行。切换到 5V USB 充电头 / 充电宝后，保持原外部模块供电及共地，理论上无需电脑即可自动互动；**换供电后的冷启动仍需用户实测**。供电与下载步骤见根目录 README。
