# 接线与装机

引脚总表见根目录 README。这里的左右按面对机器人屏幕的方向定义。

调试供电：ESP32-C3 接电脑 USB；两个 SG90 接外部稳压 5V；OLED、触摸和红外接 3.3V；开发板、舵机、所有传感器和电源 GND 必须相连。不要并联开发板与外部电源的 3.3V 输出，不要在 USB 接通时再把外部 5V 接开发板的 5V 引脚。

电源板输出颜色只适用于原装板，实际以电压和丝印为准。若使用 12V 适配器，只能接兼容的降压电源模块输入，不能直接接舵机或 ESP32。

先按 OLED → 红外 → 触摸 → 单舵机 → 双舵机的顺序空载检查。舵机回中使用 `examples/10_机械组装/servo_center.py`，回中结束后断电再装舵盘。第一只舵机轴竖直负责转头，第二只轴水平负责俯仰，两个轴互相垂直。

正式程序持续输出 PWM 保持位置，旧例子可能动作后关闭 PWM。释放 PWM 不等于回中，停止前先扶住头壳。初次上电无法知道舵机实际位置，可能直接转至中位。

GPIO8、GPIO9 保持空闲，避免影响启动。输入默认触摸高电平有效、红外低电平有效，实际模块需单独测试。当前版本不提供脱离 USB 的独立供电接法，也未进行完整装机验收。
