# 接线与装机

引脚总表见根目录 README。这里的左右按面对机器人屏幕的方向定义。

调试供电：ESP32-C3 接电脑 USB；两个 SG90 接外部稳压 5V；OLED、触摸和红外接 3.3V；开发板、舵机、所有传感器和电源 GND 必须相连。不要并联开发板与外部电源的 3.3V 输出，不要在 USB 接通时再把外部 5V 接开发板的 5V 引脚。

电源板输出颜色只适用于原装板，实际以电压和丝印为准。若使用 12V 适配器，只能接兼容的降压电源模块输入，不能直接接舵机或 ESP32。

先按 OLED → 红外 → 触摸 → 单舵机 → 双舵机的顺序空载检查。舵机回中使用 `examples/10_机械组装/servo_center.py`，回中结束后断电再装舵盘。第一只舵机轴竖直负责转头，第二只轴水平负责俯仰，两个轴互相垂直。

正式程序持续输出 PWM 保持位置，旧例子可能动作后关闭 PWM。释放 PWM 不等于回中，停止前先扶住头壳。初次上电无法知道舵机实际位置，可能直接转至默认姿势。当前默认是抬头、略向右；红外触发时再额外抬头。

GPIO8、GPIO9 保持空闲，避免影响启动。输入默认触摸高电平有效、红外低电平有效，实际模块需单独测试。

## 不连接电脑时的供电

保持现有接线，ESP32 的 USB 线改接 **5V USB 充电头或充电宝**。这只是更换主控的 USB 电源，ESP32 的 5V 和 3.3V 排针仍不接外部输出。原来的适配器和电源模块继续给舵机、OLED、触摸、红外供电，所有 GND 保持共地。

扶住头部，断开外接电源和 USB，再接好新的 USB 电源。启动时先给电源模块通电，让屏幕和传感器有电，再给 ESP32 USB 通电，避免 OLED 初始化时找不到屏幕。停止时先扶住头，拔外接电源，再拔 USB。

9 个正式文件保存到设备根目录后，`main.py` 会自动启动；不需要电脑、Thonny 或 Wi-Fi。只接 ESP32 USB 而拔掉模块电源，不能运行整机。部分充电宝会因低负载自动关闭，可改用稳定的 5V USB 充电头。

2026-10-18 已验证板上文件、USB 重启和动作指令，用户确认新版动作正常、没有异响；换充电头后的离线供电启动仍需用户实测。出现异响或突然掉头，先断电检查固定、齿轮、供电和间隙，不要硬扭舵机或继续扩大动作。
